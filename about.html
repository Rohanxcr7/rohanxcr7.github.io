About Panenka

Panenka is a name inspired by my long-time love and support for football. As a football fan, I chose this name to represent creativity and confidence, inspired by the famous Panenka shot.

This website is my trial project created to practice and improve my web development skills. It is part of my learning journey, and more features will be added over time.
